Files:
- index.html: complete responsive study website (HTML, CSS, and JavaScript in one file).

How to publish with GitHub Pages:
1. Create a new GitHub repository, for example: advanced-robot-control-study-hub
2. Upload index.html to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish the site and open the generated URL.
